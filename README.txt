BHAUJA BIRTHDAY WEBSITE — QUICK START

1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Open index.html in your browser (or use the VS Code Live Server extension).
4. Add your photos in assets/photos/ using these exact names:
   - bhauja-1.jpg   (Bhauja's photo)
   - together-1.jpg (your photo together)
   - family-1.jpg   (a family photo)
5. To personalize the birthday letter, edit the text inside the letter section in index.html.
6. The website adapts to phones and computers.

NOTES
- The Google Fonts import needs an internet connection; fallback fonts are provided.
- This starter version does not include background music yet.
- To share online, publish the project using GitHub Pages. Keep personal photos private if you do not want them publicly accessible.
